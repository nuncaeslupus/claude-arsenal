sync_duplicates.py --apply resolves declared sibling paths against the wrong
base, so its cross-check loop can never find a file and warns that every
sibling is missing while looking at a repo where all of them exist.

apply_canonical (sync_duplicates.py:182) computes:

    repo_root = library_root.parent.resolve()

With the default --library plugins/skill-workshop/skills, that is
plugins/skill-workshop. Declared paths in a DUPLICATED ACROSS SKILLS header are
repo-root-relative, so (repo_root / declared) builds

    plugins/skill-workshop/plugins/core/skills/init/assets/bin/check_skill_workshop_loaded.sh

which cannot exist. Same base error at :166 for canonical_rel, so the canonical
file's own declared path is not removed from declared_paths and gets warned
about too. Observed live while syncing the fail-open hook fix: two warnings,
both false, for two files that were present.

    warn: declared sibling missing on disk: plugins/core/skills/init/assets/bin/check_skill_workshop_loaded.sh
    warn: declared sibling missing on disk: plugins/skill-workshop/hooks/check_skill_workshop_loaded.sh
    ok:   synced .../assets/bin/check_skill_workshop_loaded.sh

The sync itself is correct: targets is already populated at :180 from the
discovered Path objects. The declared-paths loop is a belt-and-braces check that
is inert and only produces noise — which is worse than absent, because an
operator running --apply on a security-critical file is told the siblings are
missing at the exact moment they need to trust the tool.

The file already has the right helper: _repo_root() (:70) walks up to a Makefile
or .git, and discover() uses it at :113. apply_canonical does not.

Done means: --apply resolves declared paths against _repo_root(), warns only
when a sibling is genuinely absent, and has a test — it currently has none,
which is how an entirely inert loop shipped.


## Acceptance gate

```bash
# --apply must not warn about siblings that are present. Syncing an
# already-identical group is a no-op, so this is safe to run repeatedly.
out=$(uv run python plugins/skill-workshop/skills/skill-workshop/scripts/sync_duplicates.py \
        --apply plugins/skill-workshop/hooks/check_skill_workshop_loaded.sh 2>&1)
echo "$out"
echo "$out" | grep -q "missing on disk" && { echo "false 'missing' warning still emitted" >&2; exit 1; }
exit 0
```
