### Finding
A default `/init` changes GitHub branch protection on the default branch, inserts a 'built with claude-arsenal' badge into the host README, registers a project-level `statusLine`, installs an Actions workflow and rewrites CLAUDE.md. README Quick start and INSTALL mention none of the first three, there is no `--dry-run`, and attribution has no opt-out flag (only a config key after the fact). A user following the two-line quick start gets a remote repo setting changed without having been told.

### Evidence
grep -i 'branch.protection|badge|statusline' README.md docs/INSTALL.md → only the repo's own CI badges; grep '"--dry-run"|"--no-attribution"' init.py → none; only `--no-branch-protection` exists.

### Suggested direction
List every write (local and remote) in README/INSTALL before the command, make branch protection and the README badge opt-in (or ask in the setup interview), and add an init `--dry-run`.
