**Where:** `plugins/core/skills/init/assets/bin/record_skill_load.sh:9-25, plugins/core/hooks/hooks.json:40-49`

### Finding
record_skill_load.sh is a PostToolUse hook of the core plugin and creates <repo>/tmp/arsenal-metrics/skill-loads.tsv on every Skill call in any project where the plugin is enabled, with no check that the repo uses arsenal. Projects that never ran /init get an untracked tmp/ directory that `git add -A` (which the bundle's own scripts use) will commit.

### Evidence
Read the script: the only guards are symlink checks; compare detect_surface.sh which is a no-op without arsenal/session/.

### Suggested direction
Skip unless arsenal/ (or claude-arsenal/) exists at the repo root, as detect_surface.sh does.
