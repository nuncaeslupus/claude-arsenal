Plan T7–T8. Spec §§ 4.3, 4.4, 5.4.

- `create_repro.py --id IDX --format curl|python`: the handoff from "found the endpoint" to "have a scraper". Every value escaped for its destination — single-quoted with the embedded-quote escape for shell, `repr()` for Python, `--data-raw` so a body starting with `@` stays data. A generated command that executes something the capture did not contain is the worst bug this toolkit could have.
- `create_har.py`: `--keep`/`--drop`, `--drop-types`, bodies dropped by default with `--keep-bodies` opting back in and saying what that means, `--redact` by default, using the same salted fingerprint the index uses — a literal `<redacted>` marker would make every `Authorization` in the derived file compare equal and break `--headers` on it, and an `--output` equal to the input refused before anything is opened.

Gates: `adversarial_repro_shell_executions == 0`, SC6 (a public GET reproduces its captured status), SC5 (`secrets_in_bounded_fields_of_output == 0`), and the derived HAR validates as 1.2.
