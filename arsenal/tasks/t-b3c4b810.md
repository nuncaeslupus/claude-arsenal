### Finding
A fresh install has `merge-policy = "after-ci"`, no watched review bots (CI-only since 5.19) and an empty `host-gate`; resident AGENTS.md says exit 0 from merge_ready.sh 'means merge, without asking the user'. Combined with the session-start protocol auto-picking queue work, an unattended session in a repo whose CI is thin merges agent-written code to the default branch with only its own subagent review.

### Evidence
Read the default config template (init.py:95-114) and AGENTS.md § Completion; the setup interview offers `after-ci` as the default answer and declining it keeps that default.

### Suggested direction
Default to `never` (human merges) until the interview is answered; make auto-merge an explicit opt-in.
