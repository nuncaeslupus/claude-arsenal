### Finding
The resident protocol says idea/spec/plan work must go through `explore-idea`, `specify` and `design` and that 'another plugin's brainstorming or planning skill does not replace them'. Those three live in the optional `workflow` section; a `minimal` install (core only) gets an instruction to use skills that are absent and to refuse the alternatives it does have. INSTALL claims core is always installed because 'the vendored session protocol names those skills directly'.

### Evidence
sections.json puts explore-idea/specify/design under `workflow`; init.py has no code tailoring AGENTS.md by section (grep AGENTS.md + section/strip/filter → none).

### Suggested direction
Condition that paragraph on the workflow section being installed (init can emit it), or move it into the workflow skills' own descriptions.
