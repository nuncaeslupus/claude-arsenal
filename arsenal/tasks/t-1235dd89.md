### Finding
CLAUDE.md says a red merge is never tagged 'because consumers gate updates on exactly the newest remote tag'. UPDATE.md states `/plugin update` 'fetches the tip of main' and that the manifest takes no version, so the install route the docs call 'the common one' receives every merge, tagged or not, green or not, and has no rollback.

### Evidence
marketplace.json plugin entries use `source: ./plugins/<name>` with no ref/version; UPDATE.md's own rollback section confirms no pin exists. Live /plugin behaviour not exercised.

### Suggested direction
Publish from a `release` branch that only moves on a tagged green commit, or document pinning the marketplace to a tag ref.
