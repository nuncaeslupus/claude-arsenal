Plan T4–T5. Spec §§ 4.2, 5.2, 5.3.

- `_filters.py`: one selection grammar, index-only predicates evaluated before any body-touching one — that ordering is what keeps SC3 true.
- `query_har.py` select and show: `--list-only`, `--show IDX`, `--json`, `--fields`. Three-state cache flags (`--no-cache` selects false ONLY; `--unknown-cache` is its own flag).
- Output discipline: hard 4096-byte budget in every default mode, `--json` staying parseable by dropping whole entries from a fixed envelope, and both escapes — `--limit 0` and `--output PATH` — as first-class.
- Extract modes: `--extract-body --output-dir` with flattened, sanitised, containment-verified names; `--json-path`; `--css`/`--xpath` over a documented subset that refuses what it does not support by name; `--schema`.

Gates: `max_default_output_bytes <= 4096` in every mode (SC1); the `--json` envelope still parses under the budget with `shown`/`matched`/`truncated` intact and whole entries dropped; both escapes (`--limit 0`, `--output PATH`) return the full set; `commands_to_locate_endpoint <= 2` (SC4); `extracted_files_outside_output_dir == 0`.
