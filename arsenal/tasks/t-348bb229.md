**Severity:** medium · **Confidence:** medium · **Category:** tests

**Where:** `plugins/core/tests/create_reader_test.sh:19-26, plugins/core/tests/reader_layout_test.sh:18-23, plugins/core/tests/render_diagrams_test.sh:113-115, .github/workflows/ci.yml:118-140, Makefile:145-147`

### Finding
create_reader_test.sh (562 lines) and reader_layout_test.sh exit 0 with 'SKIP' when python3 lacks `markdown` and uv is absent; the `core tests` job installs only setup-python (no uv, no markdown), and `make test` prints just `ok <file>` for exit 0, discarding the SKIP line. The reader half of render_diagrams_test.sh and reader_check_test.sh skip the same way. If the runner image has no uv, the reader (the artifact every spec/plan hand-off depends on) is untested in CI while showing green.

### Evidence
Read the skip branches and the CI job steps; Makefile:146 captures output and echoes only `ok`. Whether ubuntu-22.04 runners preinstall uv was not verified.

### Suggested direction
Install uv (or `pip install markdown`) in the core-tests job and make `make test` surface SKIP lines / fail on SKIP in CI.
