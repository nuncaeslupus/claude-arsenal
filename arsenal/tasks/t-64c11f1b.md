### Finding
The description says 'Use when the user wants to resume work' and the body lists bare 'continue' and 'resume' as load triggers. A user saying 'continue' mid-conversation about unrelated work can load the skill, which claims a task on GitHub (a remote ref, assignment and label) and starts a worker loop.

### Evidence
Read the frontmatter and 'When to load'; the claim step (line 46) is a remote write.

### Suggested direction
Scope the trigger to queue wording ('next queue task', `/queue-next`) and require an empty in-flight context before claiming.
