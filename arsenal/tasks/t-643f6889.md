### Finding
Protocol step 7 says write `arsenal/session/handover.md` and '/session-end does this in full'. The skill writes `status/handoff.md`, only when the CLAUDE.md marker is `handoff=yes`, and switches to `arsenal/session/handover.md` only when an `arsenal/project/<WORKSPACE>/` folder exists. In a queue repo with no workspace, or with `handoff=no|ticket`, running /session-end leaves the file step 5 of the next session reads unwritten. Two spellings (handoff/handover) and two locations compound it.

### Evidence
Traced AGENTS.md step 7 → session-end Step 1 marker table and the Workspace-aware paragraph; create_handoff.py default output is status/handoff.md.

### Suggested direction
Make session-end always refresh arsenal/session/handover.md when arsenal/ exists, independent of the status/handoff.md marker.
