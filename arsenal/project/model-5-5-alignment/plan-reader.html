▸Architecture overview

One decision point replaces four independent review habits. review_sources.py looks at what external checks actually did on the PR, decide() turns that plus the verification profile and the change's risk into one instruction (no local review / diff review / full review; run or skip the local full suite), and every caller — execution, github, ship, worker, the orchestrator — reads that line instead of choosing for itself. Rounds are counted per branch, each round carries a time and test budget, and a passing full-suite run is recorded by tree hash so nothing pays for it twice.

▸Data flow

push → CI + bots act on PR
        ↓
review_sources.py --pr N [--trigger]   (reads checks, reviews, bot comments; posts one trigger if needed)
        ↓ decision line
caller: none → merge path | diff/full → adversarial_review.sh emit (budget line) → reviewer → verdict
        ↓
merge precondition: CI green on head SHA, or a gate receipt for the tree
