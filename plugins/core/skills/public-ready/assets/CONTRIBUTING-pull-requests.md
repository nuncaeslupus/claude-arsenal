# Contributing

Thanks for taking an interest.

## Issues

Bug reports, ideas and questions are welcome:
[open an issue](https://github.com/{{repo}}/issues/new/choose) and pick the
template that fits. For a security problem, do not open an issue — see
[SECURITY.md](SECURITY.md).

## Pull requests

1. **Open an issue first** for anything bigger than a typo, so we agree on the
   change before you spend time on it.
2. Keep a pull request to one change, with tests for any behaviour it changes.
3. Make sure the checks pass. A first-time contributor's checks wait for the
   maintainer's approval before they run; that is expected.
4. By submitting a pull request you agree it is licensed under this
   repository's licence.

Every pull request is reviewed before merging; changes to workflows, build
scripts and dependencies get the closest look.
